# Rewind

Буфер повтора для Windows в духе NVIDIA ShadowPlay: программа всё время пишет последние минуты экрана и звука, а по горячей клавише сохраняет их в MP4.

*A lightweight Windows replay buffer: always records the last N minutes of your screen and sound and saves them to MP4 on a hotkey.*

## Возможности

- **Буфер повтора** на 1–60 минут; сохранение по `Ctrl+Alt+F10`, из окна или из трея. Можно сохранять сколько угодно раз подряд — каждый раз выходят последние N минут.
- **Запись на видеокарте:** кадры не покидают видеокарту, кодирует аппаратный H.264 (NVIDIA, AMD, Intel). Процессор занят примерно на 1 %.
- **Звук на отдельных дорожках:** всё вместе, игра, голосовой чат (Discord, TeamSpeak, Telegram и другие), микрофон.
- **Быстрое сохранение:** чтение буфера и кодирование звука идут параллельно.
- **Уведомление** в правом верхнем углу экрана после сохранения (в запись не попадает).
- **Прицел поверх экрана** — несколько форм и цветов, в запись не попадает.
- **Окно в терминале** в зелёном стиле, управляется мышью и клавиатурой; сворачивается в трей.
- **Автозапуск с Windows** сразу в трей.
- **Портативная версия:** настройки рядом с программой.

## Установка

Скачайте со страницы [Releases](../../releases):

- `Rewind-<версия>-setup.exe` — установщик (без прав администратора);
- `Rewind-<версия>-portable.zip` — распаковать и запустить `Rewind.exe`.

Нужна Windows 10/11 x64.

## Сборка

Нужны [Rust](https://rustup.rs) (MSVC) и Windows SDK (для иконки в `.exe`).

```powershell
cd app
cargo build --release
```

## Устройство

| Модуль | Что делает |
|---|---|
| `capture.rs` | захват экрана (DXGI Desktop Duplication) |
| `gpu.rs` | перевод кадров в NV12 на видеокарте (D3D11 Video Processor) |
| `mf.rs` | кодирование H.264 / AAC и сборка клипа (Media Foundation) |
| `recorder.rs` | буфер из 10-секундных кусков на диске |
| `audio.rs` | звук по дорожкам (WASAPI) |
| `tui.rs` | окно (ratatui) |
| `shell.rs`, `tray.rs`, `overlay.rs`, `notify.rs` | горячие клавиши, трей, прицел, уведомления |
